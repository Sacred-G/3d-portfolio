# Custom Photos for 3D Screens

Add your own images here to replace the baked photos in the 3D model.

## File naming convention
- `photo1.jpg` → replaces `light_pic1` (screen 1, slot 1)
- `photo2.jpg` → replaces `light_pic2` (screen 1, slot 2)
- `photo3.jpg` → replaces `light_pic3` (screen 1, slot 3)
- `photo4.jpg` → replaces `light_pic4` (screen 2, slot 1)
- `photo5.jpg` → replaces `light_pic5` (screen 2, slot 2)
- `photo6.jpg` → replaces `light_pic6` (screen 2, slot 3)
- `photo7.jpg` → replaces `light_pic7` (screen 3, slot 1)
- `photo8.jpg` → replaces `light_pic8` (screen 3, slot 2)
- `photo9.jpg` → replaces `light_pic9` (screen 3, slot 3)
- `photo10.jpg` → replaces `light_pic10` (screen 4, slot 1)
- `photo11.jpg` → replaces `light_pic11` (screen 4, slot 2)
- `photo12.jpg` → replaces `light_pic12` (screen 4, slot 3)
- `photo13.jpg` → replaces `light_pic13` (fallback/default image)

## Supported formats
- `.jpg` (recommended)
- `.png`
- `.webp`

## How it works
1. Place your images in this folder with the correct names
2. The app will automatically load and apply them to the 3D screens
3. Click on screens to cycle through the photos (same behavior as before)

## Tips
- Use images with similar aspect ratios for best results
- Recommended size: 1024x1024 or larger for sharp display
- The images will have a subtle glow effect applied automatically
